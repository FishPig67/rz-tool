# rz-tool

Die veröffentlichten Seiten zu meiner Fantasy-Football-Dynasty-Liga
(FishPig RedZone). Zu sehen unter **https://fishpig67.github.io/rz-tool/**

Der Inhalt dieses Repositories wird erzeugt, nicht von Hand geschrieben. Jede
Seite entsteht im nicht-öffentlichen Werkzeug `dynasty-tool` aus einem
Datenbündel und wird von dort hierher kopiert und committet. Änderungen direkt
in diesem Repository werden beim nächsten Lauf überschrieben.

Jede Seite trägt ihre Herkunft: den Namen des Datenbündels, das Datum des
Datenstands und die SHA-256 der Dateien, aus denen gerechnet wurde.

Die Seiten sind vollständig eigenständig — kein Skript, kein Stil, kein Bild
und keine Schrift von aussen. Sie funktionieren im Browser genauso wie als
lokale Datei ohne Netz.
